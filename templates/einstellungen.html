AHPT – Asymmetric HTTP Polling Tunnel
Sicherer Fernzugriff ohne offene Ports · DMS-Import via Android-App
Wie es funktioniert: Der AHPT-Agent läuft auf diesem Server und pollt den bplaced-Relay. Die Android-App verbindet sich über denselben Relay — Ende-zu-Ende-verschlüsselt via Noise IK. Endanwender können so Dokumente direkt in den DMS-Importordner hochladen, von überall, ohne VPN.
